# Owner-only tasks

Steps only the owner can do: accounts, keys, payments, legal review, iOS signing, App Store. The autopilot adds rows and never blocks on them. The list is in the order you should do things. Every key row names the variables and says exactly where each goes and where to get it; `knowledge/env-and-accounts.md` has the full detail for every variable. Commands are for PowerShell. Nothing after row 6 is needed to build or to run the app on this PC: it runs with dev sign-in, fake fares, a file outbox, local storage and `AI_PROVIDER=claude_cli`, and `npm run doctor` lists what is optional.
