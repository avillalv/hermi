| 2026-10-03 | setup | The context reset is a fresh session for every unit of work, and the driver ships. A Node driver (`scripts/autopilot/run.mjs`, standard library only) runs each build prompt as short headless `claude -p` sessions (plan, one per ticket or sub-step, ship) and itself waits for the required `ci` check and merges, only when every ticket has an APPROVE from an Opus model. | Claude's auto mode blocks an AI from merging a pull request no human approved, and long single sessions drift. State in git, GitHub, `PROGRESS.md` and `.autopilot/state.json` survives restarts and usage limits. | Merge by hand (`gh pr merge --squash`), or use the interactive alternative in `KICKOFF.md`. |
| 2026-10-03 | setup | Models: plan and FINAL sessions run `claude-opus-5-5`; ticket, ship and ci-fix sessions run `claude-sonnet-5-5`. A PreToolUse hook allows only these agents and rejects a mismatched model. If the weekly Opus limit is hit the run pauses. | Sonnet for volume and cost, Opus only for judgement, and no silent fallback to a weaker reviewer. | Change `--model` in `scripts/autopilot/run.mjs` and the agent files in `.claude/agents/`. |
