# ADR 0001: Product name

Status: provisional go (2026-10-04). Becomes final when the attorney opinion below is in.

## Decision

The product is called **Hermi**. App Store name: `Hermi: Group Trip Planner`. Product domain: `hermi.world`, with `heyhermi.com` as a redirect. Source: `app-buildout/brand/BRAND.md`.

## Fallback names

If the search or the opinion blocks Hermi: **Twoyage**, then **Zigroam**. Both had the .com and .app unregistered and no App Store app on 2026-09-30. Re-run the checklist below for the fallback before switching.

## Trademark search checklist (owner and attorney)

Run each item, record the date and result next to it.

- [ ] USPTO search (TESS replacement, "Trademark Search") for `HERMI` in class 9 (downloadable software, mobile apps).
- [ ] Same in class 39 (travel planning and arrangement services).
- [ ] Same in class 42 (SaaS, software as a service, non-downloadable software).
- [ ] Phonetic and one-letter variants in all three classes: HERMIO, HERMY, HERMEE, HERMES.
- [ ] Live and dead marks noted separately. For each live hit: owner, class, goods text, status.
- [ ] EUIPO and WIPO Global Brand Database search for the same terms (the iOS app ships worldwide).
- [ ] App Store and Google Play name search: "Hermi: Thinking Journal" (known, unrelated journaling app) and "Hermio - Trip manager" (known, same category).
- [ ] Attorney opinion on **Hermio**: one letter away, trip planner on iOS and Android, same category. Ask: likelihood of confusion, and whether Hermi can coexist.
- [ ] Attorney opinion on **Hermes (Hermès)**: the luxury house defends its name actively. Ask: risk for a travel app name, and for the Greek-god origin as a defence.
- [ ] Logo check: stays clear of Hermès orange and brown and of any horse or carriage (BRAND.md).
- [ ] Decision recorded: go, go with changes, or switch to a fallback.
